### Program Pengelolaan Data Toko 

Program ini merupaksan sistem sederhana pengelolaan data toko khususnya toko Motor (Dealer). Dalam program ini user bisa melihat semua produk yang dijual, menambahkan kategori (warna), mengubah harga produk, dan menghapus kategori.

#### Yang ada di dalam program ini :

`Nested dictionary` ==> ini digunakan untuk menyimpan data produk yang dijual

`if-else` ==> ini digunakan untuk membuat kondisi pilihan sesuai yang diinginkan user dan validasi jika pilihan tidak ada dalam opsi

`while` ==> ini digunakan untuk membuat loop pada menu awal agar program jalan terus menerus sampai user menginginkan berhenti/keluar
